Doom Updated - Fabric 1.21.11

- Glossy dunkles GUI, Right Shift oeffnet das Menue
- Kategorien: Combat / Visuals / Obv
- Hit Delay: verzoegert DEINE Schlaege auf Entities um 0-500 ms
  * Einstellen per Slider im Combat-Tab
  * An/Aus per Numpad 1 (Standard) oder Button im Menue
  * Taste in den Minecraft-Steuerungen aenderbar (Taste "1" waere die Hotbar)
  * Einstellungen werden in config/doomupdated.properties gespeichert

Bauen: GitHub Actions (.github/workflows/build.yml) oder lokal mit JDK 21 + "gradle build".
JAR: build/libs/doom-updated-1.0.0.jar
